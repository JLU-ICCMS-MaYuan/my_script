## 📖 单步计算

### 1. 结构优化

#### 固定晶胞优化
```bash
qe relax \
    -i structure.vasp \
    -w ./relax_output \
    -j slurm \
    -m mode=relax ecutwfc=80 kpoints='6 6 6'
```

#### 可变晶胞优化
```bash
qe relax \
    -i structure.vasp \
    -w ./relax_output \
    -p 10  # 压强10 GPa
    -j slurm \
    -m mode=relax-vc ecutwfc=80 kpoints='6 6 6'
```

### 2. 声子计算

```bash
qe phono \
    -i relax.out \
    -w ./phonon \
    -j slurm \
    -m mode=nosplit qpoints='6 6 6'
```

### 3. 电子能带和态密度

```bash
qe electron \
    -i relax.out \
    -w ./electron \
    -j slurm \
    -m mode=eleproperties kpoints_dense='16 16 16'
```

## 🔄 Pipeline批量计算

### 预定义流程1：优化→声子→超导

```bash
qe pipeline \
    -t relax-phono-sc \
    -s "structures/*.vasp" \
    -w ./batch_sc \
    -j slurm \
    --max-workers 8 \
    -m qpoints='6 6 6' ecutwfc=80 mu_values='0.10 0.13'
```

**流程步骤**：
1. 结构优化 (relax-vc)
2. 密K点自洽 (scffit)
3. 稀K点自洽 (scf)
4. 声子计算
5. 声子态密度
6. Lambda计算
7. Tc计算（多个μ值）

### 预定义流程2：优化→电子性质

```bash
qe pipeline \
    -t relax-electron \
    -s "structures/*.vasp" \
    -w ./batch_electron \
    -j slurm \
    -m ecutwfc=80 kpoints='6 6 6'
```

## ⚙️ 参数参考

### 基础参数

| 参数 | 默认值 | 说明 | 有效范围 |
|------|--------|------|----------|
| `ecutwfc` | 80 | 波函数截断能 [Ry] | 20-200 |
| `ecutrho` | 320 | 电荷密度截断能 [Ry] | ecutwfc×4 |
| `degauss` | 0.05 | 展宽参数 [Ry] | 0.02-0.10 |
| `mixing_beta` | 0.3 | SCF混合参数 | 0.1-0.7 |

### 收敛参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `conv_thr` | 1.0d-8 | SCF收敛阈值 [Ry] |
| `forc_conv_thr` | 1.0d-6 | 力收敛阈值 [Ry/Bohr] |
| `electron_maxstep` | 200 | SCF最大迭代步数 |

## ❓ 常见问题

### Q1: SCF不收敛怎么办？

**解决方案**：
1. 增加 `electron_maxstep` 到300
2. 调整 `mixing_beta`（金属用0.3，绝缘体用0.7）
3. 使用更密的k点网格
4. 检查结构是否合理

### Q2: 声子谱有虚频怎么办？

**解决方案**：
1. 确保结构充分优化（`forc_conv_thr < 1.0d-6`）
2. 增大 `degauss` 参数（从0.02到0.05）
3. 使用更密的k点网格进行SCF
4. 如果是Gamma点虚频，结构可能不稳定

### Q3: 如何选择合适的k点密度？

**建议**：
1. 使用收敛性测试工具：
```bash
qe convergence \
    -i structure.vasp \
    -t kpoints \
    -r 4,6,8,10,12
```
2. 一般规则：晶胞越大，k点可以越稀疏
